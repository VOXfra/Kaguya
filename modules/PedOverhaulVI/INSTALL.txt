PED OVERHAUL VI — 0.6.1

TARGET
- GTA V Enhanced Story Mode

REQUIRES
- Script Hook V
- ScriptHookVDotNet Enhanced

INSTALL
- PedOverhaulVI.dll and PedOverhaulVI.ini go in GTA V\scripts\.
- Police Overhaul VI is optional; when loaded, it owns law-enforcement peds.

COGNITION / SOCIAL MEMORY
- bounded civilian/gang cognition based on actual sensory triggers, not magic player knowledge
- attention, suspicion, certainty, fear and morale
- direct observation is separated from social warning/crowd inference
- masks alone can attract attention but do not manufacture panic
- bodies, weapons, gunfire, fire, fights and vehicle hazards have different confidence/severity paths
- distraction, social memory, causal threat memory and commitment windows reduce reaction thrashing
- vehicle occupants remain under Rockstar driving AI until a dedicated driver/occupant layer is implemented safely

0.6.1 STORY-FIRST CORRECTION
- removed the old exception that let Ped Overhaul keep running inside a Rockstar mission merely because the player was wanted or shooting
- mission flag, cutscene, protagonist switch, loss of player control and fades now always suspend Ped Overhaul
- the runtime waits five seconds after Rockstar returns control before resuming free-roam cognition
- mission entities remain ineligible even outside the global story guard

There is no personality menu, awareness bar, debug overlay or sandbox event spawner in normal play. No vanilla archive is replaced.
