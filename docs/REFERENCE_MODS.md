# Police reference mods (research only)

The following user-supplied releases were inspected as behavioral references. Their binaries/assets are not committed or redistributed.

- BetterChaseRemade
  - reference: witness/search logic, warrants, vehicle recognition, PIT/lethal authorization, mission compatibility concerns.
- Better Chases+ Enhanced 1.1.0
  - reference: Enhanced/SHVDNE architecture and API constraints.
- Dispatch Reworked 2.1
  - reference: staged dispatch, jurisdictions, specialized response and six-star-style escalation.
- PullMeOverRemade 3.3-A
  - reference: traffic stops and citations rather than immediate combat escalation.
- VI Wanted System
  - reference: face/clothes/vehicle recognition concepts; its visible search/identification HUD is intentionally not adopted.
- Immersify 2.4
  - reference: camera/world-event awareness and NPC reaction concepts.
- No Cop Blips
  - reference: desired player-facing map behavior.

Police Overhaul VI is an original implementation. Reference projects are not copied into this repository.
