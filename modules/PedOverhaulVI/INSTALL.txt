PED OVERHAUL VI — V0.4.1

TARGET
- GTA V Enhanced Story Mode

REQUIRES
- Script Hook V
- ScriptHookVDotNet Enhanced

INSTALL
1. Copy the contents of this package into the GTA V root directory.
2. PedOverhaulVI.dll and PedOverhaulVI.ini must end up in GTA V\scripts\.
3. When updating from an older version, overwrite BOTH the DLL and INI.

MODULARITY
- Police Overhaul VI is NOT required.
- If Police Overhaul VI is loaded, it owns law-enforcement peds while Ped Overhaul VI handles civilians/gangs/ambient NPCs.
- Vehicle occupants remain under Rockstar driving AI until the dedicated vehicle/world-life layer owns those behaviours.

V0.4.1 COGNITION HARDENING
- keeps the 0.4 anti-thrashing and Distraction Runtime architecture
- repeated shared-scene observations are pulsed instead of being treated as a fresh shock every processing pass
- mask-only observation can cause a glance/attention trace but can no longer accumulate into Concerned or ThreatConfirmed by itself
- pure line-of-sight to an otherwise ordinary player no longer forces every passer-by into a Glance task
- a static body can make a ped strongly concerned but cannot by itself prove an active killer is still present or force Panic
- a visible armed threat may reach ThreatConfirmed, but without gunfire/direct violence it is prevented from self-amplifying into automatic Panic
- panicking peds keep an already committed survival action when a lower-priority body cue becomes dominant
- survival commitment is lengthened so Cover/Flee/Cower/Freeze actions have time to visibly play instead of cycling every few seconds
- emergency replanning is further rate-limited

V0.4 COGNITION STABILITY + DISTRACTION RUNTIME
- fixes panic task thrashing: Freeze/Cover/Cower/Flee no longer replace one another every tick
- survival decisions use a configurable commitment window
- cognition integrates the real elapsed time between player observations
- mask detection uses the actual mask component; ordinary head props are not automatically treated as face coverings
- stage downgrades use hysteresis so awareness does not flicker around thresholds
- phone/mobile scenarios are detected as genuine visual/social distraction
- filming, conversation, eating/drinking and smoking are modeled as different distraction strengths
- distracted peds can take longer to notice a low-key weapon, mask, body or crowd cue
- direct aiming, visible shooting and imminent danger can break through distraction
- distraction also degrades confidence in shared-scene events

V0.3.1 SAFETY BASE
- vehicle occupants are never assigned pedestrian flee/cower/navmesh tasks
- vehicle-hazard thresholds are tightened for normal traffic
- social panic propagation is damped

V0.3 SHARED-SCENE-AWARENESS BASE
- attention / suspicion / certainty / fear cognitive model
- shared scene scanner for NPCs, vehicles, bodies, fire and explosions
- NPC-vs-NPC fights, external gunfire and visible hostile weapons
- social information propagation with imperfect confidence
- vehicle trajectory / closest-approach / time-to-impact awareness
- discreet withdrawal, watch, film, phone, cover, flee, surrender and morale behaviours
- personality-driven reactions and bounded processing

No vanilla archive is replaced.
