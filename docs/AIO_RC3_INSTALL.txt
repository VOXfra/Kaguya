RC3 CONTROL POLICY
No arbitrary mod hotkey is required for the new RC3 systems.
- Context remains GTA Context: E / D-pad Right.
- Melee remains GTA native melee controls.
- InteriorRuntimeVI only intercepts Context when it has positively identified a nearby locked DoorSystem door in free roam.
- VOXCoreVI now exposes a central expiring control-ownership arbiter for VOX systems. Claims are cleared while Rockstar owns a mission/cutscene/switch/fade.

NEW RC3 FOUNDATIONS
PhysicalCharacterVI:
- Full leg IK in normal locomotion and melee-aware leg IK during fights.
- Slope-aware footing with a small movement-rate reduction only on meaningful inclines.
- Subtle continuation inertia on sharp running/sprinting direction changes.
- Collision/deceleration bracing with short stumbles only above bounded thresholds.

AnimationRuntimeVI:
- Central priority/expiry animation request bridge.
- Optional target alignment and facing before an animation begins.
- Story ownership cancels VOX animation claims instead of fighting Rockstar tasks.
- Designed for future door, carry, melee, object and contextual transitions.

InteriorRuntimeVI:
- Discovers real GTA DoorSystem entries from nearby props instead of using a hard-coded door list.
- Locked DoorSystem doors can receive a short physical handle-test using E / D-pad Right.
- It never changes the lock state during a handle test.
- Mission-owned props are excluded.
- Persistent interior/room circuit-state bridge is included for the future light switch / breaker / CCTV / powered-door layer. RC3 does NOT fake room lighting where GTA exposes no safe room-local switch control yet.

AcousticRuntimeVI:
- Detects player gunshots and models an acoustic event with weapon energy, suppressor state, distance, obstruction, interior and room membership.
- Same-interior/same-room, different-room and interior/exterior listeners receive different attenuation.
- Nearby free-roam civilians can orient to an inferred sound position or flee strong nearby reports without being given magical player coordinates as an identity fact.
- Acoustic events are published into VOXCoreVI world memory for future police/evidence integration.
- This is NOT yet real DSP/reverb replacement; it is the shared propagation/hearing foundation.

MeleeRuntimeVI 0.2.0:
- Keeps RC2 longer-fight health/damage pacing.
- Adds a stamina-driven melee defense layer.
- Native block input becomes substantially more effective while stamina remains.
- Repeated holding/attacking drains stamina; backing off regenerates it.
- A successfully timed block can open a short counter window; pressing a native melee attack in that window can stagger the current close opponent.
- No custom combat hotkey or minigame.
