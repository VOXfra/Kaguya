INVENTORY RUNTIME VI — 0.2.0

Requires Script Hook V + Script Hook V .NET Enhanced.
Copy scripts/InventoryRuntimeVI.dll into GTA V\scripts\.

Physical trunk inventory:
- stand behind a non-mission vehicle and hold H
- select a radial action, then release H to store the equipped weapon or retrieve a stored weapon
- the trunk opens, the protagonist performs a physical pickup animation, and the transfer occurs afterwards
- each physical vehicle has its own persistent five-weapon capacity
- ammunition is preserved; no weapon is silently deleted

Accessory wheel:
- while on foot in free roam, hold M
- select mask, glasses, or headwear and release M
- removing an accessory remembers it separately for each protagonist so it can be put back on
- the wheel does not create arbitrary clothing; it only toggles an accessory the character has actually worn

Story Mode safety:
- mission entities are never used as storage
- missions, cutscenes, character switches, fades, and loss of player control suspend the runtime
- a five-second grace period prevents the wheel from reopening as Rockstar returns control

This build deliberately keeps transfers explicit and reversible. The carried-weapon category limit remains disabled until its migration path can guarantee that existing Story Mode loadouts are preserved.
