POLICE OVERHAUL VI — V0.5.2 TEST BUILD

TARGET
- GTA V Enhanced Story Mode

REQUIRES
- Script Hook V compatible with the installed GTA V Enhanced build
- Script Hook V .NET Enhanced (SHVDNE) v1.1.0.6 or compatible newer build

INSTALL
1. Copy the contents of this package into the GTA V root directory.
2. PoliceOverhaulVI.dll and PoliceOverhaulVI.ini must end up in GTA V\scripts\.
3. Copy/overwrite scripts\PoliceOverhaulVI\UI\ too: V0.5.2 restores the original high-resolution VOX face/clothes/vehicle/red-star HUD assets.
4. Do NOT delete Cases.xml or CrimeScenes.xml unless you intentionally want to erase persistent police memory.
5. Launch modded Story Mode with BattlEye disabled as required by Script Hook V.

NO VANILLA ARCHIVE IS REPLACED.

V0.5.2 HUD / IDENTIFICATION FIXES
- low-resolution placeholder-looking HUD icons are replaced/restored with the original high-resolution VOX assets
- a historical vehicle in a case file no longer creates a phantom current vehicle badge while the suspect is on foot
- a genuinely tracked flagged vehicle can remain an active vehicle signal after the suspect abandons it, because the tracker follows the vehicle rather than the player
- uncovered face recognition now accumulates during sustained direct observation instead of getting stuck forever below the FaceKnown threshold at medium distance
- active pursuit wanted stars are drawn as one stable 1-to-6 row using GTA's internal commonmenu star texture; GTA itself only stores five native wanted slots, so VOX owns the visual row when the internal sixth tier is active
- after the active wanted phase, the search HUD can switch back to the original red VOX star/evidence treatment
- death/respawn explicitly clears the active HUD phase without erasing persistent case memory

V0.5 SEARCH OWNERSHIP / ACTIVE SIGNALMENT
- A free-roam chase can enter a Police Overhaul owned CustomSearch after sustained loss of direct police/CCTV contact.
- During CustomSearch, vanilla police are temporarily told to ignore the Player entity so a one-frame glimpse cannot magically reacquire the suspect.
- Reacquisition requires continuous physical observation and a concrete current match; losing LOS resets the confirmation timer.
- Historical evidence and CURRENT signalment are separate.
- Current vehicle/outfit/mask descriptors can become invalid after an unseen change.
- A genuinely identified face remains historical identity evidence.
- Trackers locate the flagged VEHICLE and update its search position; they do not magically locate a replacement vehicle or driver body.
- Search duration scales by threat and high-level searches expand to district scale.

HUD SEMANTICS
- face = police genuinely learned the exposed face
- clothes = currently actionable outfit signalment
- vehicle = currently actionable vehicle signalment, or a still-active tracked flagged vehicle
- no badge is created merely because old evidence exists in the persistent file

WORLD / INVESTIGATION
- persistent case, warrant, traffic and crime-scene data remain retained
- abstract long-lived crime-scene zone markers are disabled in the current config while physical scene lifecycle work continues
- serious evidence can persist internally without leaving a flashing/yellow zone around a normal-looking home for hours

OTHER SYSTEMS RETAINED
- physical witnesses and delayed reporting
- CCTV reporting/re-identification
- ANPR-style plate matching and deterministic trackers
- proportional force / PIT separation and civilian-risk checks
- sixth-star military escalation
- traffic camera enforcement and vehicle-ownership-aware citations
- GTA Online police-vehicle support when models exist
- mission-safe passthrough
