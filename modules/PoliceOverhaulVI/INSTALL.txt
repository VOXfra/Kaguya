POLICE OVERHAUL VI — V0.1.0

TARGET
- GTA V Enhanced Story Mode

REQUIRES
- Script Hook V compatible with the installed GTA V Enhanced build
- Script Hook V .NET Enhanced (SHVDNE) v1.1.0.6 or compatible newer build

INSTALL
1. Copy the contents of this package into the GTA V root directory.
2. PoliceOverhaulVI.dll and PoliceOverhaulVI.ini must end up in GTA V\scripts\.
3. Launch Story Mode with BattlEye disabled as required for script mods.

UNINSTALL
- Delete scripts\PoliceOverhaulVI.dll
- Delete scripts\PoliceOverhaulVI.ini
- Delete scripts\PoliceOverhaulVI\ to remove logs and persistent police cases.

NO VANILLA ARCHIVE IS REPLACED BY V0.1.

V0.1 SYSTEMS
- Physical witnesses and delayed reporting.
- CCTV reporting/re-identification from world camera props.
- Hidden face/outfit/weapon/suspect-count/vehicle/color/plate evidence.
- ANPR-style plate matching and deterministic vehicle trackers.
- Last-known-position search centering with no police blips/search HUD.
- Persistent cases and warrants per protagonist.
- Home stakeouts for active warrants.
- Traffic camera/police speeding citations and delayed fines.
- Custom support dispatch from 3 stars upward.
- Sixth-star military tier: heavy ground units, attack helicopter and jet, plus an extra HUD star.
- Mission-safe passthrough and custom-unit cleanup.

This is the first COMPLETE SYSTEMS PASS. Test point by point and send scripts\PoliceOverhaulVI\PoliceOverhaulVI.log if anything behaves incorrectly.
