VEHICLE RUNTIME VI — 0.4.0

Target: GTA V Enhanced Story Mode / free roam.
Requires Script Hook V and Script Hook V .NET Enhanced v1.1.0.6 or compatible newer build.

Install:
- copy scripts/VehicleRuntimeVI.dll to GTA V\scripts\

PHYSICAL VEHICLE THEFT — NO MOD MENU / NO MINIGAME
- normal unlocked/personal vehicle entry is left to GTA
- a real attempt to enter a locked ambient vehicle becomes one bounded physical lock-working action
- the protagonist turns to the lock and uses an existing Rockstar physical animation
- there is no theft wheel, lockpick puzzle, progress game or 2D overlay
- higher security tiers take longer and can trigger the alarm
- successful access hands directly back to GTA's normal enter task
- if an unkeyed stolen vehicle is already running, it stays running
- if it is stopped, its ignition takes a short physical-state delay before starting; no hotwire minigame
- stolen/hotwired/tracker state persists per model + plate identity

INTENTIONAL REMOVALS FROM 0.3
- removed the two-direction theft wheel
- removed the six-direction in-vehicle control wheel
- removed custom seatbelt/window/light/lock control UI; ordinary vehicle functions remain vanilla
- tracker state is still recorded, but 0.4 does not let the player magically disable it bare-handed. A future tool/inventory system can expose that action physically.

STORY MODE SAFETY
- mission entities are never lock-managed
- mission flag, cutscene, protagonist switch, loss of player control and fades suspend the runtime
- free-roam ownership resumes only after a five-second grace period

The runtime is additive and does not modify vanilla archives/RPF files.
