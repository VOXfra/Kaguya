POLICE OVERHAUL VI — V0.4.0

TARGET
- GTA V Enhanced Story Mode

REQUIRES
- Script Hook V compatible with the installed GTA V Enhanced build
- Script Hook V .NET Enhanced (SHVDNE) v1.1.0.6 or compatible newer build

RECOMMENDED
- VOX Core VI 0.1.0. Police 0.4 continues to run without it, but shared world events are then not persisted in the common VOX memory.

INSTALL
1. Copy the contents of this package into the GTA V root directory.
2. PoliceOverhaulVI.dll and PoliceOverhaulVI.ini must end up in GTA V\scripts\.
3. When updating, overwrite BOTH DLL and INI.
4. Keep scripts\PoliceOverhaulVI\UI\ if you already installed the private VI-style face/clothes/vehicle/star PNG assets.
5. Launch Story Mode with BattlEye disabled as required for script mods.

NO VANILLA ARCHIVE IS REPLACED.

V0.4 WORLD CONTINUITY
- Serious wanted incidents create persistent crime-scene records in scripts\PoliceOverhaulVI\CrimeScenes.xml.
- Returning later can reveal a bounded investigation zone plus physical-style evidence markers rather than an empty location.
- Nearby violent/fatal evidence can strengthen/extend an existing scene instead of creating duplicate scenes.
- Crime scenes decay over configurable real-time hours according to severity.
- With VOX Core installed, crime scenes are also published to the shared persistent world memory.
- BOLO merchant recognition is enabled after a serious prior case when the suspect face was genuinely identified.
- Recognition requires a nearby streamed merchant, clear line of sight, exposed face and a short confirmation period.
- The merchant then makes a delayed discreet report; it does not magically know the current suspect position after the player leaves.
- Masking the face blocks merchant face recognition.

V0.3 SYSTEMS RETAINED
- confidence-based face/outfit/vehicle identification and re-identification
- physical witnesses and delayed reporting
- CCTV reporting/re-identification
- ANPR-style plate matching and deterministic trackers
- persistent cases, warrants and home stakeouts
- proportional force / PIT separation and civilian-risk checks
- sixth-star military escalation
- bounded search HUD + death cleanup
- traffic camera enforcement and vehicle-ownership-aware citations
- GTA Online police-vehicle support when models exist
- mission-safe passthrough with free-roam pursuit ownership hysteresis
- iFruit-style fine notification + persistent TrafficMail.log archive

KNOWN LIMITATION: VANILLA MAIL APP
- Arbitrary persistent text cannot safely be inserted into Story Mode appEmail through SHVDNE alone.
- FiveM/Cfx ADD_TEXT_ENTRY is not a GTA V native and is intentionally not used.
- Until an Enhanced-specific GXT2 text-bank/hook is packaged, traffic fines use the iFruit notification plus TrafficMail.log history.

CRIME-SCENE SCOPE IN 0.4
The first runtime provides persistence, investigation zones and evidence marks. Forensic officers, tape/barriers, coroners, EMS, tow trucks and staged cleanup are future scene-lifecycle layers and are not claimed as implemented yet.

TESTING
Delete scripts\PoliceOverhaulVI\PoliceOverhaulVI.log before a clean test. Useful checks are:
- return to a serious crime location after escaping
- enter a shop unmasked after a 4+ star case in which the face was identified
- re-identification by police using known face/outfit/vehicle evidence
- tracker-led searches
- five-to-six-star escalation and search duration
- death/respawn HUD cleanup

Compile success proves SHVDNE API compatibility, not every runtime behavior. Runtime logs remain the source of truth.
