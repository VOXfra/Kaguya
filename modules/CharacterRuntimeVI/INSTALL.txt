CHARACTER RUNTIME VI — 0.2.0

Requires Script Hook V + Script Hook V .NET Enhanced.

INSTALL
- copy VOXBodyMorphVI.asi into the GTA V root directory
- copy scripts/CharacterRuntimeVI.dll into GTA V\scripts\

FITNESS / SPORT
- separate persistent fitness profile per protagonist/model
- sprinting/running/swimming train endurance slowly; melee and swimming contribute to strength/lean mass
- recognised real workout locations/props use Rockstar's WORLD_HUMAN_MUSCLE_FREE_WEIGHTS scenario
- Context starts/stops the physical session; there is no workout menu, stat-selection screen, repetition minigame or countdown HUD
- completed physical sessions credit bounded progression; cancelled sessions do not
- endurance and strength produce small bounded gameplay effects

STORY MODE SAFETY
- mission flag, cutscene, protagonist switch, loss of player control and fades disable progression and return gameplay modifiers to vanilla values
- body morph output is disabled while Rockstar owns the scene
- a five-second grace period prevents custom modifiers/body output from snapping back during mission handoff
- workout rewards are rejected while Rockstar owns the scene

VISIBLE BODY CHANGE
CharacterRuntimeVI writes a narrowly bounded body target to scripts\CharacterRuntimeVI\BodyMorphState.txt. VOXBodyMorphVI.asi validates the current ped transform before any write and fails closed if the expected entity layout is not found. Width remains capped at +4.5%; height is never changed.

The native body bridge is still experimental. Compile success is not runtime proof: BodyMorphBridge.log remains authoritative during Enhanced testing.
